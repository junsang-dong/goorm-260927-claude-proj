# Nordvik 할인 수익성 계산기

BCR 영업마케팅팀이 Nordvik Automation向け 견적 할인 요청을 검토할 때 사용하는 단일 HTML 파일 기반 웹 애플리케이션입니다. 별도의 서버나 빌드 과정 없이 브라우저에서 `nordvik-discount-calculator.html` 파일을 열기만 하면 바로 사용할 수 있습니다.

## 무엇을 하는 도구인가요

Nordvik 구매팀에서 들어온 세 가지 할인 요청 시나리오를 놓고, 할인율을 조정했을 때 **주문 이익률**이 목표치(30%)와 최저 허용치(25%) 대비 어디에 위치하는지 즉시 계산해 보여줍니다. 영업 담당자가 고객과 협상하기 전에 "이 정도까지는 재량으로 승인 가능한지, CFO 검토가 필요한지, 재협상이 필요한지"를 스스로 판단할 수 있도록 돕는 내부 검토용 계산기입니다.

## 주요 기능

- **시나리오 탭 3종**: 파일럿 셀 1기 / 양산 1차 12셀 / 연간 프레임 30셀 — 각 시나리오는 고객이 실제로 보낸 요청 문구와 함께 표시됩니다.
- **견적 라인 편집**: 품목(BCR-A200 / A100 / C100), 수량, 할인율을 라인별로 조정하거나 라인을 추가/삭제할 수 있습니다.
- **수량할인 자동 반영**: 10~49EA는 −5%, 50~99EA는 −10%가 하한선으로 자동 적용되며, 그 이상 할인한 만큼이 "예외 할인"으로 구분됩니다.
- **전체 라인 일괄 할인 슬라이더**: 모든 라인에 동일한 할인율을 한 번에 적용합니다.
- **주문 수익성 요약**: 정가 합계, 할인 후 매출, 표준원가·수출 포장비·보증 충당금·수출 서류/CE 대응비를 차감한 최종 주문 이익과 이익률을 표시하고, 목표/하한 기준 대비 판정(영업 재량 승인 / CFO 검토 필요 / 재협상 권고)을 보여줍니다.
- **할인율 대비 이익률 곡선 차트**: 균일 할인율을 0~35%까지 움직였을 때 이익률이 어떻게 변하는지 SVG 그래프로 시각화하고, 목표/하한 구간을 색상 밴드로 구분합니다.
- **역제안 카운터**: 목표 이익률(30%)과 최저 허용 이익률(25%)을 유지하기 위한 최대 균일 할인율을 자동 계산합니다.
- **시나리오 비교 테이블**: 세 요청을 동일한 원가 가정으로 나란히 비교합니다.
- **원가·정책 가정 패널**: 품목별 재료비/노무비/제조간접비/포장비, 목표·최저 이익률, 보증 충당률, 수출 서류비, 참고 환율 등을 모두 직접 수정할 수 있습니다. 이 값들은 제품 마스터에 없는 예시값이므로 실제 사용 전 CFO 확인이 필요합니다.

## 데이터 출처 구분

- **정가·수량할인**: 제품 마스터 v2.1(2026-06-15) 확정값
- **원가·정책 기준값**(재료비, 노무비, 제조간접비, 목표/최저 이익률, 보증 충당률 등): 예시값이며 실사용 전 CFO 검증 필요

## 사용 방법

1. `nordvik-discount-calculator.html` 파일을 브라우저로 엽니다 (더블클릭 또는 `open nordvik-discount-calculator.html`).
2. 상단 탭에서 검토할 시나리오를 선택합니다.
3. 견적 라인의 품목/수량/할인율을 조정하거나, 우측 상단 슬라이더로 전체 라인에 일괄 할인을 적용해 봅니다.
4. 우측 패널에서 실시간으로 바뀌는 주문 이익률과 판정 결과, 역제안 가능 할인율을 확인합니다.
5. 필요 시 하단 "원가·정책 가정"을 펼쳐 실제 CFO 원가 데이터로 값을 교체한 뒤 재계산합니다.
6. "요청값으로 되돌리기" 버튼으로 언제든 원래 고객 요청 조건으로 리셋할 수 있습니다.

## 기술 스택

- 순수 HTML/CSS/JavaScript (프레임워크·빌드 도구 없음)
- 외부 의존성은 Google Fonts(IBM Plex Sans KR, IBM Plex Mono) 뿐이며, 인터넷 연결이 없어도 폰트만 시스템 기본값으로 대체되고 기능은 정상 동작합니다.
- 라이트/다크 모드를 시스템 설정에 따라 자동 전환합니다.

## 주의 사항

이 계산기는 **내부 검토용**입니다. 고객에게 나가는 정식 견적과 납기 확약은 해외영업(심수정)·CFO(박민재)의 검토를 거쳐야 하며, 현재 원가 항목은 제품 마스터에 없어 예시값으로 채워져 있으므로 실제 의사결정에 사용하기 전 반드시 실제 원가 데이터로 교체해야 합니다.
